# Дашборды

Живые экраны остаются в Metabase и в этот репозиторий не входят. Ниже — состав карточек и формула, которой карточка подписана. Выгрузки строк и списки сотрудников не приложены.

Описание обобщено: без названий компании, внутренних отчётов и реальных объёмов.

## Показатели за период

Дневные и периодные показатели службы поддержки. Каналы: голос, чат, почта.

| Карточка | Что считает |
|---|---|
| Всего поступило | Вход в службу. Голос: из меню и прямые в очередь. Чат: сессии. Почта: письма в очереди |
| Поступило на оператора | Из входа те, кто дошёл до рабочей очереди |
| Без оператора | Не дошли до очереди. Почта всегда 0: письмо сразу в очереди |
| Потеряно | Дошли до очереди и не получили ответ. На голосе короткое ожидание до 5 с в потери не входит |
| SL | Голос: ответ за 30 с. Чат: за 240 с. Почта: за 24 ч |
| SL по времени | Та же формула, по часам или по дням |
| AHT | Голос: разговор и поствызывная. Чат: от распределения до закрытия. Почта: от назначения до ответа |
| ASA | Среднее ожидание тех, кто дошёл до оператора |
| A1RT | Только чат: от распределения до первой реплики оператора |
| CSI оператора и бота | Средняя оценка 1–5, одна последняя на обращение |
| Объёмы по времени | Вход, на оператора, потеряно и без оператора на одной оси |
| Сервис по дням | Таблица входа, очереди, SL и AHT |
| Операторы | Состав на линии, только если выбран сегодняшний день |

## Оперативный экран

Отдельный дашборд на сегодня. В общий экран показателей не встроен. Формулы сервиса те же. Плюс снимок статусов: кто на линии, чем занят, загрузка за день.

## Классификация обращений

Отдельный экран по темам. Сумма тем равна входу той же воронки, что карточка «Всего поступило». Сутки 00:00–00:00.

| Карточка | Что считает |
|---|---|
| Итог за период | Число сессий входа |
| Обращения по классификации | Темы за выбранный период |
| Топ обращений | Те же сессии, другой разрез |
| Топ отклонений | Те же сессии, другой разрез |

Фильтр сегмента на этой копии делит вход на несколько взаимоисключающих долей (например: авторизованный клиент, приоритетный сегмент, остальные). Вместе доли дают весь вход. Этот экран не заменяет исходный отчёт классификации в учётной системе.
