# Синтетические данные

Файлы в этой папке **выдуманы**. Это не история обращений, не фамилии сотрудников и не показатели какой-либо компании. Они нужны только для того, чтобы было видно, какие поля ждут загрузчик и SQL-витрины.

| Файл | Зачем |
|---|---|
| `voice_queued_calls.csv` | Попадания звонка в очередь (`voice_queued_calls`) |
| `voice_call_legs.csv` | Плечи звонка: соединение и окончание разговора оператора |
| `chat_session_iterations.csv` | Итерации чата и почты |
| `agent_status_changes.csv` | Статусы оператора, в том числе `wrapup` для поствызывной |
| `dim_projects.csv` | Справочник проектов/очередей |
| `dim_employees.csv` | Справочник сотрудников (логины `agent_01`…) |
| `v_interval_volume.sample.csv` | Пример того, как выглядит витрина нагрузки по 30 мин — чтобы читать пайплайн, не поднимая DuckDB |
| `events.csv` | Пример календаря акций и сбоев (в консоли рабочий файл — `inputs/events.xlsx`) |

Два синтетических дня: понедельник и вторник, 16–17 марта 2026 года. Очереди и входы совпадают с заглушками в `py/wfm_settings.py`. Операторы — `agent_01` … `agent_08`, отдел «Отдел поддержки».

Как положить это в хранилище Parquet (после `pip install -r requirements.txt`):

```bash
python py/load_sample.py
```

Скрипт запишет файлы в `data/<таблица>/sample.parquet`. Этого достаточно, чтобы открыть DuckDB и посмотреть витрины. Пункты меню, которые ходят в живую реплику или в модуль Erlang A, без них по-прежнему не выполнятся.
